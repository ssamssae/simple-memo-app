# 메모요 개인정보처리방침

시행일: 2026년 6월 2일

이 문서는 메모요 앱의 개인정보 처리 기준을 설명하는 표준 초안입니다. 최종 게시 전 운영자의 검토가 필요합니다.

## 1. 처리 원칙

메모요는 회원가입 없이 사용할 수 있는 로컬 중심 메모 앱입니다. 앱의 기본 메모 데이터는 사용자의 기기 내부에 저장되며, 운영자는 사용자의 메모 내용을 서버로 전송하거나 별도 서버에 저장하지 않습니다.

## 2. 수집하는 개인정보

메모요는 기본 사용 과정에서 이름, 전화번호, 이메일 주소, 계정 정보 등 개인을 직접 식별하는 정보를 운영자 서버로 수집하지 않습니다.

사용자가 직접 메모에 입력한 내용은 사용자의 기기에 저장됩니다. 메모 내용에 개인정보가 포함될 수 있으므로, 이용자는 민감한 정보를 입력하거나 공유할 때 주의해야 합니다.

## 3. 권한 및 외부 서비스

앱은 백업, 가져오기, 공유 등 사용자가 선택한 기능을 수행하기 위해 기기 또는 외부 앱의 기능을 사용할 수 있습니다. 예를 들어 사용자가 Drive 백업을 실행하면 Google 계정 인증과 Drive 저장 기능이 사용될 수 있습니다. 이 경우 외부 서비스 이용에는 해당 서비스 제공자의 약관과 개인정보처리방침이 적용됩니다.

## 4. 이용 목적

앱이 기기 안에서 처리하는 데이터는 메모 작성, 수정, 삭제, 정렬, 백업, 가져오기, 공유 등 사용자가 요청한 기능을 제공하기 위해서만 사용됩니다.

## 5. 보관 및 삭제

메모 데이터는 기본적으로 사용자의 기기에 보관됩니다. 사용자가 앱에서 메모를 삭제하거나 앱 데이터를 삭제하거나 앱을 제거하면 기기 내 데이터가 삭제될 수 있습니다. 외부 백업을 만든 경우 해당 백업의 삭제는 사용자가 해당 외부 서비스에서 직접 관리해야 합니다.

## 6. 제3자 제공 및 처리위탁

운영자는 메모요의 기본 사용 과정에서 이용자의 개인정보를 제3자에게 판매하거나 제공하지 않습니다. 사용자가 외부 백업, 공유, 가져오기 기능을 직접 실행하는 경우 해당 기능 수행에 필요한 범위에서 외부 플랫폼이 사용될 수 있습니다.

## 7. 아동의 개인정보

메모요는 아동을 대상으로 개인정보를 의도적으로 수집하지 않습니다. 보호자는 기기와 앱 사용을 적절히 관리할 수 있습니다.
