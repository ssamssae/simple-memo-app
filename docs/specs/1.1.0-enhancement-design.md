## 0. 결론

1.0.7이 `휴지통 30일 / UNDO / 공유 / Drive 1버튼`으로 "데이터를 잃지 않게"를 끝냈다면, 1.1.0은 "메모를 더 빨리 찾고, 더 빨리 구조화하고, 더 빨리 여는 것"에 집중하는 게 맞다.

**권고 묶음**
- **1.1.0 포함**: 검색, 태그, 정렬, 위젯
- **1.1.x 후퇴**: 다기기 sync

이유는 단순하다. dogfood에서 가장 자주 부딪히는 문제는 "동기화"보다 "찾기", "분류", "즉시 진입"이다. sync는 가치가 크지만 충돌/정책/트리거가 더 무겁다.

## 2. 1.1.0 권고 범위

### 2.1 검색

**역할**
- 메모가 많아질수록 가장 먼저 체감되는 기능.
- 기본 검색은 `firstLine + content + tags` 대상 substring 검색으로 충분하다.

**설계**
- 로컬 인덱스 없이 선형 검색으로 시작.
- 입력 디바운스 250~300ms.
- 기본 결과는 활성 메모만.
- 하이라이트는 1.1.0에서 있으면 좋지만 필수는 아님.

**1.0.7 증분성**
- `Memo.firstLine`, `Memo.content`, `Memo.isFavorite`, `deletedAt`를 그대로 재사용 가능.
- 검색 자체는 데이터 이동이 아니라 로컬 UX라 리스크가 낮다.

### 2.2 태그

**역할**
- "이 메모가 뭐였지?" 다음 단계는 "이 메모를 어떤 묶음으로 볼지"다.
- dogfood에서는 책/업무/아이디어 같은 느슨한 군집이 유효하다.

**설계**
- 자유 태그 칩 기반.
- 저장은 `Memo.tags: List<String>` 추가.
- 정규화 규칙은 단순하게:
  - trim
  - 중복 제거
  - 대소문자/공백 정리
- 고정 카테고리보다 자유 태그를 우선.

**1.0.7 증분성**
- 메모 본문 포맷은 그대로 유지하고, JSON에 필드 하나만 더 얹는 수준.
- 백업/복원 흐름과 충돌이 적다.

### 2.3 정렬

**역할**
- 검색이 "찾기"라면, 정렬은 "보이게 하기"다.
- 목록 기본 탐색 비용을 낮춘다.

**설계**
- 정렬 모드 최소 세 가지:
  - 최근 수정순
  - 즐겨찾기 우선
  - 제목순
- 기본값은 현재 UX를 최대한 보존.
- 사용자가 자주 바꾸는 순서가 아니라, "현재 맥락에 맞는 보기" 정도로 둔다.

**1.0.7 증분성**
- 현재의 즐겨찾기 그룹 + reorder 로직 위에 얇게 얹을 수 있다.
- 데이터 모델 변경 없이 UI 정렬 규칙만 추가할 수 있다.

### 2.4 위젯

**역할**
- 앱을 열기 전 한 번 더 여는 지점.
- dogfood에서 가장 작은 마찰로 큰 효용을 만드는 진입점.

**설계**
- 1x1: 앱 바로 열기 / 최근 메모 1개
- 2x2: 새 메모 + 최근 메모 + 즐겨찾기 진입
- 구현 라이브러리는 `home_widget` 계열의 iOS WidgetKit + Android AppWidget 브리지로 잡는 쪽이 현실적이다.

**1.0.7 증분성**
- 백업/공유처럼 외부 전송이 아니라 로컬 진입면이라 CS 부담이 낮다.
- 다만 플랫폼별 native 설정이 필요하므로 검색/태그보다 난이도는 높다.

## 3. 1.1.x 로 넘길 것

### 다기기 sync

**왜 지금이 아닌가**
- 1.0.7의 안전망과는 달리, sync는 충돌 해석이 핵심이다.
- tombstone, merge policy, 트리거 정책, 백엔드 분기까지 같이 결정돼야 한다.
- "알아서 맞춰짐"이 가치인데, 지금 넣으면 정책 설명이 길어진다.

**왜 나중인가**
- 1.0.7의 Drive 백업/복구 자산은 재사용 가능하지만, 제품 난이도는 별도다.
- 검색/태그/정렬/위젯이 먼저 있어야 sync 후에도 사용자가 "뭘 동기화하고 싶은지"가 선명해진다.

**1.0.7 기반 증분성**
- 인프라 일부는 재사용 가능:
  - Google sign-in
  - Drive API
  - JSON 직렬화
  - 삭제 tombstone 스키마
- 하지만 제품 단위로는 1.1.x 신규 축이다.

## 5. dogfood 판단 기준

1. 내가 매일 "찾는" 빈도가 높은가.
2. 내가 매일 "분류"하는 비용을 줄여주는가.
3. 내가 앱을 열기 전에 더 자주 들어가게 만드는가.
4. 지금 넣으면 1.0.7 안전망을 흔들지 않는가.

이 기준으로 보면 1.1.0은 검색/태그/정렬/위젯이 맞고, sync는 1.1.x가 맞다.
