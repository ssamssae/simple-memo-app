**divergence 주의 ①** — spec §1.3 은 Drive 백업 폴더를 `appDataFolder`(비공개) 로 권장·"결정 펜딩"이었으나, **실제 코드는 가시 "Memoyo" 폴더 + `drive.file` scope + folderUrl 반환(사용자가 폴더 열기)** 로 이미 구현됨. spec 의 appDataFolder 권장은 **superseded**. 본진이 (a) 현 가시폴더 유지 (b) appDataFolder 로 재작업 중 택1 — 권장 (a)(이미 동작·테스트, 가시폴더가 "다른 기기서 직접 확인" UX 에 유리, drive.file scope 라 타 파일 접근 0).

**divergence 주의 ②** — spec §1.7 은 라벨을 "메모 내보내기→메모 백업"이라 했으나 실제 코드 라벨은 이미 "Drive 에 백업 / 메모 가져오기 / 가져오기 되돌리기". 라벨 재설계는 ① UI 통합 시 일괄.

**SDK skew 주의** — origin/main 커밋 `5bc8cb0`이 `onReorderItem→onReorder` 로 revert(Flutter 3.41.9 빌드). 5노드 SDK skew(3.41↔3.44) 회귀 클래스([[feedback_5node_sdk_skew_cascade_regression]]). 새 위젯/리오더 코드 추가 시 **`onReorder` 시그니처 유지** + 빌드환경 정합 확인(ack 게이트 아님, 주의).

## 1. 현 코드베이스 구조 (구현자 onboarding)

- **상태관리**: 라이브러리 없음. `MemoListScreen`(StatefulWidget) 의 `_MemoListScreenState._memos: List<Memo>` 단일 소스. 모든 변경 = `setState` + `_saveMemos()`. 자식(`_MemoSwipeItem`)엔 콜백 주입.
- **영속화**: `MemoStorage` → `SharedPreferences` 단일 JSON blob, key `'memos'`. SQLite 아님. `SnapshotStore`(key `'memos_pre_import'`) = import 1슬롯 undo.
- **모델**: `Memo { id, content, isFavorite, createdAt, updatedAt }` + `copyWith` / `toJson` / `fromJson` / `encodeList` / `decodeList`. (origin/main 에서 `deletedAt` 없음 — diff 0 확인.)
- **서비스**: `DriveBackupService`(sealed result 타입으로 에러 분기), `ExportImportService`(`mergeSilently` id기반 updatedAt-wins, `importFromSource` 스냅샷후 merge, `undoImport`).
- **화면**: `splash → memo_list`(메인) / `memo_edit`(작성·공유) / `settings`(앱평가·이용약관·개인정보, ListTile 행 + `PolicyScreen` sub-screen 푸시 패턴) / `policy`.
- **버전**: `1.0.7+27`. 표기 `VersionFooter` 가 `--dart-define=APP_VERSION` 주입.

## 2. 핵심 설계 결정 — soft-delete 데이터 모델 (②+④ 공통 기반)

②(삭제 UNDO durable)와 ④(휴지통)는 **단일 soft-delete 모델**로 묶는다. spec §2 가 이미 결정한 방향 = **`Memo.deletedAt` 필드 추가, 단일 `'memos'` blob 유지, 필터는 UI 책임**. 현 아키텍처(단일 blob)와 정합하고 마이그레이션 0(기존 메모 = `deletedAt` 없음 → null = 활성). 별도 trash store 분리안은 두 blob 정합 부담이 커 **기각**(메모요 메모 수 적어 필터 성능 차이 0).

> 이 결정은 spec 이 이미 내린 것이라 **재투표 불요**. 단 본진이 "별 store 분리"를 원하면 codex-mesh-vote 후보. 권장 = spec 그대로 `deletedAt` 단일 blob.

### ②+④ 삭제 UNDO(durable) + 휴지통 30일

**데이터 모델 변경 (`lib/models/memo.dart`)**: spec §2.2 그대로.
