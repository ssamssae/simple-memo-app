## ⚠️ 가격 숫자를 일부러 안 적었다

배차는 「₩3,300 과 일치하는지 대조」를 요구했으나 **그 값을 실측으로 확인하지 못했다.**
- ASC `/v1/inAppPurchases/{id}/iapPriceSchedule` → **HTTP404**
- 앱 코드에도 가격 상수 없음 (grep 0건 — 스토어가 런타임에 주는 값이라 정상)

확인 못 한 숫자를 박으면 **이번에 고치려는 불일치를 새로 만드는 셈**이라 초안은 가격을 단정하지 않는다.

## 사후 정정 (2026-08-05, T-260805-124)

초안 최초본의 `[개인정보]` 문단에 **사실이 아닌 문장**이 있었다:

> 이름·이메일·위치 등 어떠한 개인정보도 수집하지 않습니다. (en-US: `We collect no personal data — no name, no email, no location.`)

이 초안이 바로 아래 줄에서 링크로 거는 `docs/legal/privacy-policy.md` 가 같은 항목을 정반대로 적고 있다 (2.처리하는 정보 표):

> 광고 및 앱 사용 정보 | **IP 주소에서 추정한 대략적 위치**, 기기·광고 식별자, 광고 상호작용, 앱 상호작용, 진단·성능 정보 | Google Mobile Ads SDK가 광고 제공·측정·분석·부정 이용 방지를 위해 **수집하거나 공유할 수 있음**

즉 「위치를 수집하지 않는다」고 적은 문장 세 줄 아래에 「위치를 수집한다」는 문서를 링크로 달아 둔 상태였다. 스토어 심사에서 가장 먼저 대조되는 짝이고, 폐지된 기능을 파는 것보다 무거운 종류의 불일치다.

**고친 방향** = 줄이지 않고 정확하게. 참인 부분(자체 회원가입 없음 → 이름·이메일 안 받음)은 남기고, 빠져 있던 부분(광고 SDK 의 IP 기반 대략적 위치·기기/광고 식별자 처리)을 넣었다. Drive 백업이 Google 계정 인증을 요구한다는 사실도 명시했다 — 방침 2.표의 `Google 계정 인증 정보` 행과 맞춘 것이다.

**ko·en-US 양쪽 다 고쳤다.** 같은 문장의 번역쌍이라 한쪽만 고치면 다른 쪽에 같은 거짓이 남는다.
