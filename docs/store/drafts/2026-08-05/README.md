## ⚠️ 가격 숫자를 일부러 안 적었다

배차는 「₩3,300 과 일치하는지 대조」를 요구했으나 **그 값을 실측으로 확인하지 못했다.**
- ASC `/v1/inAppPurchases/{id}/iapPriceSchedule` → **HTTP404**
- 앱 코드에도 가격 상수 없음 (grep 0건 — 스토어가 런타임에 주는 값이라 정상)

확인 못 한 숫자를 박으면 **이번에 고치려는 불일치를 새로 만드는 셈**이라 초안은 가격을 단정하지 않는다.
